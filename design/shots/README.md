# 화면 갈무리

`python tools/shots.py` 로 다시 만든다. 실제 일정은 건드리지 않는다 —
임시 APPDATA 에 본보기 자료를 심고 그 위에서 찍는다.

- **1800 × 1120** (창과 같은 900×560 을 2배로)
- 시각은 **11:00 으로 못 박았다.** 이 앱은 색이 해 높이로 바뀌므로, 찍는 시각에
  따라 밤 색이 나오면 그걸 기준으로 디자인하게 된다. `night.png` 만 00:00 이다.
- 갈무리 동안에는 전환 · 애니메이션을 끈다. 헤드리스는 가상 시간으로 돌지만
  CSS 전환은 그 시계를 따라가지 않아, 창이 반쯤 열린 채로 찍힌 적이 있다.

## 창

**900 × 560.** 참고 도안(`design/references/LazyScheduler PC 화면들 standalone.html`)의
규격이다. 하늘 206 + 종이 354. 알림 프로그램 한 창 안에서 모든 일이 끝나는
크기라 넓게 벌려 둘 이유가 없고, 대신 종이 안의 치수가 이 높이에 맞춰져 있다 —
새 항목의 달력은 28px 줄, 세 칸은 230 / 남는 만큼 / 250 이다. 더 키우면
아래 두 주가 종이 밖으로 밀려난다.

## 하늘

종이를 여러 겹 세운 디오라마다. 그림의 자는 **900 × 210** 이고, 세로는 그대로
쓰고 가로만 창 너비에 맞춰 늘린다. 뒤에서 앞으로 **하늘(그라데이션) → 먼 능선
셋 → 궤도 띠 → 구슬 → 땅 → 빛** 이고, 앞으로 올수록 그림자가 길고 짙다.

종이(새 항목 · 설정 · 달력 …)가 열리면 그림이 **통째로 114px 위로 밀려 올라간다**.
눌러 찌그러뜨리지 않는다 — 찌그러뜨리면 능선과 궤도의 비례가 그때만 달라진다.
띠 · 시각 · 구슬은 한 무리(`.rib`)로 먼저 내려앉으며 사라지고, 능선과 땅과
게으름뱅이만 남는다.

```
지평선    y=206      궤도 꼭대기 y=54      해 뜸 x=150 · 해 짐 x=760
능선      y=150 / 176 / 194 에서 시작하는 고정 곡선 (참고 도안 그대로)
띠        두께 13 · 해 뜨기 40분 전 ~ 진 뒤 40분까지
구슬      r=8.5 · 20px 안쪽은 한 알약으로 묶어 궤도를 따라 18px 씩
```

### 빛

**해도 달도 동그라미로 그리지 않는다.** 하늘에 남는 것은 빛줄기뿐이다 —
해가 어디 있는지는 궤도와 그림자가 이미 말하고 있어, 원을 하나 더 얹으면
같은 말을 두 번 하는 것이 된다. 낮에는 궤도 위 지금 자리에서, 밤에는 해가
지나간 쪽 하늘에서 부챗살로 내려온다.

그림자의 **방향**도 거기서 나온다. 아침에는 오른쪽으로, 한낮에는 발밑으로,
저녁에는 왼쪽으로 진다. 여섯 겹의 그림자와 게으름뱅이의 그림자가 모두 같은
값(`dir`)을 쓴다 — 하나만 따로 두면 그 겹만 다른 시각에 서 있게 된다.

### 색

```
         낮                      밤
하늘     #b7d3e6 → #e2ecf0       #141b24 → #26313c
능선     #d7e6ee/#b4cdd8/#8fb0bf #2a3744/#1f2b36/#17212b
띠       #e6ece8 (윗면 #f7f9f6)  #3a4753 (윗면 #4a5866)
지나온 쪽 #3f6f69                 #8fc2b9
빛       해 높이로 만든 노란빛     달빛 #dbe9f7
```

겹마다 낮과 밤 두 값을 짝으로 둔다. 하나의 밤빛에 몰아 섞으면 여섯 겹이
밤에 같은 회색으로 주저앉아 깊이가 사라진다.

## 땅 위

```
면        한낮 #eef2ec
글자      한낮 #1f2a28 / 보조 #5d6a67   (밤에는 뒤집힌다)
강조      #3f6f69                       (밤에는 #8fc2b9 쪽으로)
지난 것   #b0573f                       (밤에는 #f2ab97 쪽으로)
실선      rgba(31,42,40,.12) / .20
입력칸    면보다 한 겹 밝게 + 실선 한 줄, 커서가 들어가면 그 선만 청록
알약 묶음 테두리 한 겹 안에 알약, 고른 것만 청록 채움
글꼴      Paperlogy 300 · 400 · 500
크기      44 / 20 / 15 / 13 / 12.5 / 11 / 10.5
```

색은 `tokens.py` 의 `LIGHT` 를 섞어 만든다. 새 화면을 그릴 때도
`--bg` `--surface` `--text` `--text2` `--teal` `--hair` `--hair2`
`--on-teal` `--teal-inv` `--field` `--sky-hi` `--sky-lo` `--hill1..3`
`--ribbon` `--rib-hi` `--bead` `--sky-edge` `--guy` `--moon`
변수를 쓰면 빛이 바뀌는 것을 저절로 따라간다. 색을 직접 적으면 밤에 안 따라온다.

## 밝기 고정

설정 → 화면 에서 **해를 따라 · 밝게 · 어둡게** 를 고른다. 밝게는 남중,
어둡게는 자정의 빛으로 세워 둔다 (`theme` · 이 기기에만 저장된다).
시계도 궤도도 실제 시각 그대로 움직인다 — 멈추는 것은 빛뿐이다.
