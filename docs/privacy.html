개인정보처리방침

시행일 2026년 9월 21일

LazyScheduler 는 개인이 만들어 무료로 배포하는 일정 관리 프로그램입니다. 이 문서는 이 프로그램이 어떤 정보를 다루고, 어디에 두고, 어떻게 지우는지를 적은 것입니다.

로그인하지 않으면 아무것도 바깥으로 나가지 않습니다. 일정은 내 기기 안에만 있고, 프로그램은 어떤 서버와도 통신하지 않습니다. 동기화는 직접 로그인할 때만 켜집니다.

1. 무엇을 모으나

계정 정보Google 계정으로 로그인할 때, 계정 식별자와 이메일 주소를 받습니다. 어느 일정이 누구 것인지 가르기 위해서입니다.
일정 정보직접 입력한 항목의 제목, 메모, 날짜, 시각, 반복 규칙, 완료 여부, 그리고 알림 설정.

비밀번호는 다루지 않습니다. 로그인은 Google 이 자기 화면에서 처리하고, 이 프로그램은 그 결과만 받습니다.

2. 어디에 두나

  • 내 기기 — Windows 는 %APPDATA%\LazyScheduler\data.json, Android 는 앱 내부 저장소.
  • Google Firebase — 로그인한 경우에만. 계정별로 나뉘어 저장됩니다 (Firestore, 미국 리전).

Firebase 의 접근 규칙이 계정별로 잠가 두어서, 다른 사람은 로그인하더라도 자기 것만 보입니다.

3. 무엇에 쓰나

기기 사이에 일정을 맞추는 것, 그리고 알림을 띄우는 것. 이 둘뿐입니다.

광고에 쓰지 않고, 분석이나 추적을 하지 않으며, 누구에게도 팔거나 넘기지 않습니다. 프로그램 안에 분석 도구나 광고 SDK 가 들어 있지 않습니다.

4. 어디로 보내나

저장과 로그인을 위한 Google 외에는 어디에도 보내지 않습니다. 프로그램이 통신하는 곳은 이 넷이 전부입니다.

  • accounts.google.com — 로그인 화면
  • oauth2.googleapis.com — 로그인 결과 교환
  • identitytoolkit.googleapis.com · securetoken.googleapis.com — 세션
  • firestore.googleapis.com — 일정 저장

이 부분의 처리에는 Google 개인정보처리방침이 함께 적용됩니다.

5. 얼마나 두나

지우기 전까지 둡니다. 앱에서 항목을 지우면, 다른 기기에도 지워졌다고 알리기 위해 식별자만 남은 흔적이 30일 동안 남았다가 정리됩니다. 그 흔적에는 제목이나 메모가 들어 있지 않습니다.

6. 어떻게 지우나

  • 항목 하나 — 앱에서 지우면 로그인한 모든 기기에서 지워집니다.
  • 이 기기에서만 로그아웃 — 설정 → 동기화 → 로그아웃. 이 기기의 로그인 정보만 지웁니다. 기기의 일정과 클라우드에 올라간 일정은 그대로 남습니다.
  • 기기에 있는 것 전부 — Windows 는 %APPDATA%\LazyScheduler 폴더를 지우고, Android 는 앱을 삭제하면 됩니다.
  • 계정과 클라우드에 올라간 것 전부 — 앱 안에서 바로 지울 수 있습니다.
    • Windows — 설정 → 동기화 → 계정 · 클라우드 데이터 삭제
    • Android — 오른쪽 위 톱니바퀴 → 계정 · 데이터 삭제
    누르면 클라우드에 올라간 일정이 모두 지워지고, 이 앱이 만든 계정 자체가 사라지며, 로그인이 끊깁니다. 되돌릴 수 없습니다. Windows 에서는 이 PC 에 남은 일정을 함께 지울지 고를 수 있고, 고르지 않으면 기기에는 그대로 남습니다.

앱을 이미 지우셨거나 눌러도 되지 않는다면, 아래 연락처로 알려 주시면 지워 드립니다. Google 계정 설정에서 이 앱의 연결을 끊을 수도 있습니다 (연결만 끊길 뿐, 올라간 일정은 남습니다).
